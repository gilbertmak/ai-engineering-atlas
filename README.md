# AI Engineering Insight Atlas

There are more AI engineering talks than most people have time to watch. A promising title can turn into a long detour, and a YouTube description often does not give enough context to tell whether the session is worth the investment.

AI Engineering Insight Atlas is a quicker way to decide. It gathers practical talks from AI engineering conferences and organisations, then groups them into useful themes and gives each one a short, plain-language summary. The aim is not to replace the original talk. It is to help you find the ones that are likely to be worth your time.

The Atlas currently covers nine themes: System Design, Data & Eval, Reliability, Observability, Safety & Control, Deployment, Knowledge, Developer Workflows and Models & Training.

## What the application provides

- A searchable, filterable catalog of AI engineering talks by theme, tag and year
- Short summaries that explain the main idea, why it matters, when to use it and the important caveats
- A responsive detail view with direct links back to the original YouTube talk
- Lightweight tags for cross-cutting topics such as retrieval, agentic coding and model training
- Read-only MCP tools for searching the catalog, listing themes and retrieving talk summaries

Transcript review is still in progress. Unless a talk has been explicitly reviewed against timestamped evidence, its summary is an editorial synthesis of the relevant theme rather than a speaker-attributed transcript summary. This keeps the experience useful while making the level of evidence clear.

## Source and rights boundary

The Atlas links to public YouTube videos. It does not host, reproduce or claim ownership of them. All rights belong to the respective owners.

- Source metadata is checked before a video appears in the catalog.
- Topic tags come from controlled title metadata. They are useful signposts, not transcript evidence.
- Transcript-derived claims need explicit review and timestamped evidence.
- Editorial summaries should not be read as quotes or as claims made by a speaker.
- Raw transcripts, reviewer notes, API keys, OAuth tokens and service-role credentials are not part of the public project.
